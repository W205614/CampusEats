# 2026-10-11 冗余整理与部署验收

## 判断与变更

当前业务测试没有发现可证明完全重复的场景，保留全部 47 项后端回归和 10 条浏览器流程。数据库幂等/配额竞争、迁移、隔离缓存竞态、限流边界及页面操作验证的是不同风险。未用缩减数量代替测试审查，也未将可选容量压测加入日常回归。

移除 164 个 legacy 文件、22 张无数据库引用的课程 PNG、3 份旧初始化 SQL、课程反馈补丁和未使用的报表模板，共 191 个文件。运行中菜品和套餐只引用保留的 `/demo-images/dish.svg`。Flyway V1–V4、三个 Maven 模块和当前业务服务保留。历史实现可从[整理前提交](https://github.com/W205614/CampusEats/tree/f85f3e7faf36b9ef3bd8d6e4a58c33155b3a18e8)读取。

两端共享 `ApiError`，原 API 模块继续导出；`fetch`、`uni.request`、会话及提示保留各自实现。浏览器辅助函数合并，场景和断言仍在测试中。管理端 build 自带类型检查，构建脚本不重复调用；用户端类型检查继续独立执行。

浏览器使用独立命名的地址和员工，要求测试用户原购物车为空。结束或失败时恢复营业配置及原默认地址，清理自己创建的地址和购物车，取消未完成测试订单、等待已支付取消订单退款，停用测试员工/楼栋；业务历史和审计不直接删除。备份确认的原有员工未被改动。

## 验证证据

- `mvn -B -ntp verify` 修改前及修改后均通过：47 项，失败、错误、跳过均为 0。当前后端测试代码未删除。
- 管理端、H5、微信小程序源码构建和两端类型检查通过；管理端也检查测试 TypeScript。
- 从源码重建 server/web，最终完整 Chromium 流程 10/10 通过。最终 web 再创建后静态资源逐文件 SHA-256 与浏览器验证时一致，烟测再次通过。
- 首轮浏览器 8/10：集中登录触发既有 `RATE_LIMITED`。辅助函数仅对此响应轮询等待，最多 65 秒；其他错误立即失败。总测试时限调为 90 秒，生产限流不变。首轮失败和后续完整成功日志均保留在本机。
- 测试前后营业参数、三个用户原默认地址和空购物车一致。自己的临时地址与活跃配送员已清理；历史中已有的活跃测试员工保持原状态。
- 运行中 OpenAPI 与提交快照/生成类型无差异。WebSocket 合法 Origin、单次票据成功；外部 Origin、重放、伪造票据拒绝，注销关闭连接。
- 根路径原来返回 `Location: http://localhost/admin/`，丢失宿主端口；Nginx 使用相对跳转后通过烟测，CI 加入同一检查。
- 管理端 npm audit 为 0；用户端仍为已接受的 7 项高危构建依赖告警，限定接受到 2026-11-07，详见已有安全记录。

## 数据和清理

改动前及最终数据分别备份到 `.local/backups/20261011-before-cleanup`、`.local/backups/20261011-final`，文件哈希和独立数据库恢复通过。最终恢复核对 71 个订单、71 个明细、3 个用户、28 个退款任务、478 个 Outbox 事件和 11 条配额记录；订单归属、孤立明细和配额违规均为 0。重启后 16 张业务表校验和与上传文件哈希一致。

最终保留四个健康服务及原业务卷；MySQL/Redis 容器身份保持。核对 42 个其他项目容器的 ID、镜像和挂载，以及 205 个原有数据卷均保留。未执行全局 prune 或删除业务卷。原始日志、镜像清单、清理清单和检查结果保存在 `.local/cleanup-20261011`，不提交凭据、备份或生成物。

本次不含容量压测、全面故障演练、真实微信登录/真机、真实支付退款验收。GitHub Actions 的状态须以本次最终提交对应运行结果为准。
