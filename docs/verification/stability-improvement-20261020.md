# 单机稳定演示版改进与发布 · 2026-10-20

保持单体、单实例、MySQL／Redis／Java／Nginx四服务。保留演示身份、模拟支付与模拟退款，不接入真实资金、不新增公网HTTPS。备份与告警只提供工具及配置，不注册系统定时任务，本轮仅向loopback接收夹具发送通知。

## 改进及接口兼容

- 报价与首次提交统一上海业务时点；营业、活动／券、报价哈希、订单／配额日期与过期时间使用同一快照。跨日旧报价拒绝，同键已提交结果仍可恢复。
- 用户／商家／平台售后，以及商家／平台退款和通知，保持原路径和100条倒序数组，新增可选`beforeId/state/orderNumber/begin/end`；任务另支持`taskId`精确匹配。时间按上海创建日期计算，成对提供、含首尾最多366天。页面筛选、加载历史、刷新保留页数，账号／店铺变化清空状态与旧响应。
- 售后明细和举证批量读取；跨店搜索改数据库候选加批量补全，保留营业、分类、店名命中、大小写及字面子串、前200店和200条结果规则。
- V9只新增索引。V1—V8未改，没有新业务表或业务状态。
- 运维入口区分Check／Backup；项目级互斥允许同进程安全重入。完整验证备份经原始清单再次核对后才发布副本，复制中变更与损坏均拒绝。通知按异常变化／恢复发送、失败下次重试、未变化保持静默。
- 发布失败先停止候选，再比较完整DDL与Flyway历史指纹；仅完全一致且旧服务此前运行时尝试回旧镜像，迁移变化或未知状态不自动恢复数据。

## 针对性验证与四角色

首轮12个不同后端用例通过：业务日期与旧报价、103条历史翻页／筛选／HTTP校验／权限、搜索语义和边界、常数查询数、合单幂等／库存／任务范围、V8→V9逐表数据保留、优惠分摊及部分退款重试。搜索1／10／200店均为7次批量装饰查询，另有1次店铺候选查询。依赖补丁升级后另复验5个相关用例：密码迁移／改密、字符串数字JSON、幂等支付、优惠分摊及部分退款。重跑和重叠用例不作为新增覆盖。

浏览器共8项不同用例：2条完整页面旅程、2条API准备订单后的异常节点旅程、4项使用传输夹具的新列表检查。API准备隔离校区、店铺、员工和商品；完整旅程的登录、点餐、支付、备餐、配送／核销和售后在页面完成，API读取核对金额和状态。依赖补丁升级后重新执行4条角色旅程，全部通过；并非把准备阶段都算成页面操作。

| 角色 | 覆盖 |

| 用户 | 跨店／跨校区搜索加购、配送和自取合单、模拟支付、举证、连续退款、历史订单号筛选 |

初轮两项新增测试错误使用uni-app H5的原生placeholder定位；后续发现桌面日期输入也具有textbox角色，按真实DOM将订单号限定为筛选卡片中的文本输入后复验通过。未发现对应业务UI缺失，原失败截图与日志保留。依赖升级前后均未进行无关功能的本地全站回归。

两端类型检查、Docker管理端／H5／小程序构建通过；小程序构建不代表微信真机验收。脚本夹具覆盖真实锁竞争、本地HTTP通知、隐藏文件、复制期间变更与失败发布；另在真实隔离服务上完成安全备份、独立恢复、完整副本和ALARM→RECOVERED通知，重复健康检查不再次发送。副本位于同机目录，仅证明复制与完整性，不代表异地恢复。

## 有限性能测量

环境为`campuseats-improvement-acceptance`、28086及独立数据卷，10个数据库夹具身份通过普通鉴权核验。Docker引擎可见12逻辑CPU、约15.2GiB内存；容器限制沿用Compose，后端和MySQL各768MiB。2026-10-20上海时间21:52:52—21:55:53测量，无重试掩盖错误。

每档60秒，每客户端只执行1条完整下单→模拟支付→商家接单→取消申请→批准→异步模拟退款；之后为菜单、搜索及每5秒报价，循环间隔100毫秒。每身份仍受服务端真实限流，客户端写请求预算24次／61秒，本轮没有触发额外预算等待。身份准备不测登录容量。

## 依赖与安全门禁

固定Trivy0.76.0及官方归档SHA-256；CycloneDX2.9.3按同次Maven构建的实际compile／runtime依赖生成146组件清单，排除测试与provided／system范围。清单与JAR同入镜像，并由SHA-256绑定；扫描从明确镜像ID的不运行容器提取，OS和Java分别扫描、分别执行门禁。

旧Web镜像发现系统包可修复项后，改为固定摘要的Nginx1.30.6／Alpine3.24并更新系统包。新后端扫描发现17条可修复高危／严重条目，分布于Jackson2／3、Tomcat和BouncyCastle；保留Spring Boot4.1.1，使用Jackson2 BOM2.21.7、Jackson3 BOM3.1.7、Tomcat11.0.25和BC1.85兼容补丁，没有抑制公告或降低门禁。

实际候选和最终部署镜像的OS／Java扫描均完成，可修复HIGH／CRITICAL为0。部署JAR与SBOM哈希和已验收候选完全一致；Java报告0条，Web系统包报告0条，后端系统包仍有53条MEDIUM、4条LOW且当时无修复版本，完整保留。这不代表所有服务、所有工具链或整个项目零漏洞。

原Java识别库约940MiB，在GHCR与官方镜像源反复下载EOF；未将失败算通过。随后改为实际镜像内Maven运行时SBOM加Trivy主库扫描，避免每次下载该识别库。原扫描、下载和构建失败日志均保留。
