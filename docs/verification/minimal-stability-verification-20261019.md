# 最小稳定性修复验证 · 2026-10-19

本轮保留 Spring Boot 单体、单实例及 MySQL／Redis／Java／Nginx 四容器，不新增业务表、订单状态或迁移，不修改 V1—V8。真实资金、短信和第三方配送继续只保留接口。

## 改动

- 平台管理员通过独立接口改派、异常取消配送订单；校验角色、版本、同校区启用配送员和售后／退款预占，锁定订单并在同事务记录原因、前后配送员和通知。改派保留已取餐状态和原配送开始时间。异常取消复用原模拟退款及重试，不回补已消耗库存、不退券、不取消其他店铺子订单。
- 数据库连接获取3秒、行锁3秒、普通SQL5秒、事务10秒、JDBC建连2秒／读取12秒；网关等待20秒，三个客户端封装均25秒。事务内SQL使用剩余事务预算。SQL／事务超时503，锁冲突409。写请求失联或收到异常响应时提示结果未知，先刷新或按原幂等键查询，不自动重发。
- 退款、通知、合单超时、旧入口订单超时及配送超时独立调度；配送超时只有一个执行者。批量记录隔离失败，使用20／50／100条上限与5秒软预算；超时扫描游标在失败后也推进，到末尾下一轮回绕。退款和通知沿用原租约、退避和5次重试。
- 进程内记录任务开始／结束／成功时间及失败状态，失败立即可见。内部operations健康组不加入readiness，Nginx不公开该组。运维脚本检查任务停滞、失效、业务积压、无有效配送员、双向图片引用及磁盘／备份；未知检查返回非零，不自动修改业务或文件。Docker读取命令15秒、内部HTTP5秒。
