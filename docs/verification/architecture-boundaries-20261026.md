# 架构边界改进 · 2026-10-26

本轮基于8d58d55的只读审查实施，保持个人维护、单机单实例、共享演示身份与模拟资金边界。没有接入真实身份、真实支付或新增部署服务。

## 改动

- 店铺已有记录先行加锁，店长SQL不再写平台专属的启停字段；过期启停值明确拒绝。
- 取消介入在重新预占金额前检查订单仍在备餐；历史售后返回当前订单阶段，用户端据此展示入口。已配送／完成后的正常退款规则保持。
- 报表按请求序号隔离旧响应，导出绑定最后成功应用的筛选，而非尚未提交的输入。
- 评价、审计支持游标历史查询，审计增加操作人／动作／日期筛选；公开评价限定启用店铺和校区，只投影公开字段。
- 全量购物车仅处理非空店，商品批量联表读取；清空仍保留版本根。
- WebSocket票据签发和握手增加预算，Redis故障短路且不放行认证；运维详情只接受平台身份或精确限定的容器本机维护认证。
- HTTP入口按职责拆分，数据库查询留在服务；订单、退款、发现分页使用显式响应记录与生成类型，保留原有字段省略／null和角色裁剪。未将全部旧接口宣称为强类型。
- 新增V12历史索引，V1—V11不变；修正旧缓存锁和搜索上限的过时文档。
