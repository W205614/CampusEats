# CampusEats 项目审查

审查基线：仓库初始提交 `c5b0631`，以实际 `git log` 输出为准；本次审查日期为 2026-10-06。范围为本仓库 Java 后端、给定微信小程序编译代码、配套 SQL 与管理端，目标是 Docker Desktop 上的本地演示运行。

## 已修复的运行与业务问题

| 问题 | 原行为及影响 | 本次处理 |
| --- | --- | --- |
| 无容器交付配置 | 仅有 Java 源码，缺少 SQL、前端和容器启动流程 | 新增 Compose、Dockerfile、健康检查、独立持久卷和启动/烟测脚本 |
| 管理员初始密码不匹配 | 课件 SQL 的 `123456` 是明文，后端比较 MD5，无法登录 | 初始化第二个脚本转换 admin 密码 |
| MySQL 种子中文乱码 | 客户端读取课件 UTF-8 SQL 时字符集不一致，菜名和管理员名乱码 | 初始化脚本显式 `SET NAMES utf8mb4`；本次新建数据库的课件数据已纠正 |
| Redis 初始营业状态为空 | `status == 1` 对 null 拆箱，接口报错 | 默认返回打烊 0，限制设置值为 0/1 |
| 单例服务保存最近订单 | `OrderServiceImpl` 字段 `this.orders` 被后续下单覆盖，重启后为空，支付可能改错订单 | 删除共享字段，按订单号和当前用户查询；条件 SQL 限制未支付状态，重复支付不重复通知 |
| 用户访问其他人的地址/订单 | 多个用户接口仅按 ID 查询、修改或取消 | 加入地址及用户订单归属检查 |
| 客户端金额被直接持久化 | 下单 DTO 的 amount 与 packAmount 可被篡改 | 按服务端购物车计算商品总价、6 元配送费和每件 1 元包装费，匹配给定小程序的规则 |
| 缺省餐具数触发拆箱异常 | DTO 的 Integer 为 null，实体字段是 int，BeanUtils 复制失败 | 餐具数明确默认 0，包装费由服务端计算 |
| 用户 ID 和敏感日志 | ThreadLocal 未请求结束清理，日志输出完整 JWT、登录密码 DTO 和 OSS 配置 | 拦截器结束清理上下文，移除相应敏感日志 |
| 文件上传必须依赖 OSS | 无 OSS 密钥不能上传，课件历史图片 URL 返回 403 | Docker 默认本地上传与持久卷；PNG/JPEG/GIF/WebP 扩展限制和 10MB 上限；历史图片用示例图 |
| 编译产物包含开发配置 | `application-dev.yml` 包含本机数据库与第三方凭据 | Maven 资源排除开发文件，Docker 仅复制 JAR，Docker profile 通过环境变量配置 |
| 前端写死主机和服务差异 | 小程序请求旧 8080，管理端 WebSocket 写死 localhost:80，相对上传路径无法用于微信 | 仅修改项目内副本，适配 18083、当前页面 WebSocket 地址和小程序图片 URL |
| WebSocket 会话并发 | 静态 HashMap 迭代可能与连接关闭冲突，多个线程可能同时同步发送 | ConcurrentHashMap，单 session 发送同步 |

## 仍需处理的边界

1. **真实支付和退款未交付。** 现有原代码已经是模拟：调用被注释，前端也跳过 `wx.requestPayment`。本次把模拟支付设为显式开关；禁用后明确拒绝，未伪装成真实交易。退款状态目前只是本地状态更新。
2. **订单并发与真实交易仍需继续验证。** 本次功能测试后，用户取消、商家接单/拒单/取消、派送/完成和定时任务已改为条件状态更新；已验证不能重新打开完成订单。尚未覆盖多实例、真实支付回调、退款重试和压力测试。
3. **WebSocket 未鉴权。** `/ws/{sid}` 不经过双端 HTTP JWT 拦截器，仍向全部连接广播订单号。当前只监听本机，不能据此开放公网；生产要鉴权及按店铺/角色路由，并避免泄露订单信息。
4. **外部 HTTP 的超时和失败处理不完整。** 微信/百度依赖外部接口，HttpClient 工具缺少明确的整体超时与统一错误处理；真实模式还需验证密钥、网络失败和服务错误返回。
5. **员工密码使用 MD5，种子管理员密码简单。** 这是现有课件机制；本地演示可用，正式部署需要密码哈希升级、默认密码流程和登录保护。
6. **接口校验与异常响应仍不完整。** 常见无效ID、分页、菜品/套餐基本字段、订单状态、地址手机号和统计日期已补校验；尚未完成全部DTO统一校验和引用完整性验证。上传目前只校验扩展名，未验证文件内容是否为真实图片。
7. **依赖未做完整安全审计或升级。** 保留当前 Spring Boot 2.7.3 等版本以完成本地部署；本次没有运行依赖漏洞扫描，不声称生产安全或依赖无漏洞。
8. **前端为课件编译产物。** 新增可复现的请求错误、按钮恢复、模拟支付说明和桌面布局补丁，但缺少原始工程，不适合长期维护产品功能。微信账号/AppID权限、开发者工具UI、真机和正式域名均未验收。
