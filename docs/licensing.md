# 源码与依赖授权状态

本仓库当前没有项目级 `LICENSE`，维护者尚未对整套源码发布统一的开源许可。README、贡献指南和公开可访问性不表示已经选择 MIT、Apache-2.0 或其他许可证。

## 来源与第三方组件

项目保留了既有校园点餐源码及后续实现。确认对外授权前，应整理原始源码、图片和其他资源的来源及相应授权，保留已有版权、许可和 NOTICE；不能只根据新增加的代码决定全部历史内容的授权。

Java 制品随同构建生成 CycloneDX SBOM；前端版本由各自锁文件固定。组件版本与依赖关系以同次 CI 制品为准，许可证与使用条件以组件对应发行包中的 LICENSE/NOTICE 和上游声明为准。依赖的许可不自动成为 CampusEats 整个项目的许可。

## 维护要求

引入依赖或素材时记录来源、版本和授权条件，避免提交凭据、未获授权的素材及真实业务数据。需要正式对外授权时，由维护者完成来源核对后添加所选项目许可证；本轮没有代为授予或替换历史内容的授权。

参考 [GitHub 仓库许可说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)。
