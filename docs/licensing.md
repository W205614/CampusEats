# 源码与依赖授权状态

项目级开源许可证待来源核对后确定，仓库当前没有 `LICENSE` 文件。

## 来源与第三方组件

项目保留了既有校园点餐源码及后续实现。确认对外授权前，整理原始源码、图片和其他资源的来源及相应授权，并保留已有版权、许可和 NOTICE。

Java 制品随同构建生成 CycloneDX SBOM；前端版本由各自锁文件固定。组件版本与依赖关系以同次 CI 制品为准，各组件的授权条件见其发行包中的 LICENSE/NOTICE 和上游声明。

## 维护要求

引入依赖或素材时记录来源、版本和授权条件。需要正式对外授权时，由维护者完成来源核对后添加所选项目许可证。

参考 [GitHub 仓库许可说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)。
